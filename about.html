About Livebian

Livebian is a Linux distribution based on Debian 13 (Trixie). It is not a custom distribution; it is Debian in a live version.

Live use, no installation

Livebian does not include an installer. You can use it as a live user, testing and using the system or making things without installing Livebian.

You can run Livebian from a CD-ROM, SD card, USB stick, or portable HDD/SSD.

Boot support

Livebian is powered by GNU GRUB for UEFI boot and ISOLINUX for legacy boot.
